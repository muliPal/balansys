CSS Media Queries Documentation

Introduction

CSS Media Queries allow developers to apply styles based on a device's characteristics such as width, height, orientation, resolution, and more. This makes responsive design possible, ensuring web pages look good on various screen sizes.

Basic Syntax

@media (condition) {
}

Example:

body {
    background-color: white;
}

@media (max-width: 600px) {
    body {
        background-color: lightgray;
    }
}

Common Media Query Breakpoints

  • Extra small devices (phones): max-width: 480px
  • Small devices (tablets in portrait mode): max-width: 768px
  • Medium devices (tablets in landscape mode, small laptops): max-width: 992px
  • Large devices (desktops, laptops): max-width: 1200px
  • Extra large devices (large desktops, TVs): min-width: 1201px

Media Query Features

1. Width and Height

@media (min-width: 768px) {
    body {
        font-size: 18px;
    }
}

2. Orientation

@media (orientation: landscape) {
    body {
        background-color: lightblue;
    }
}

3. Resolution

@media (min-resolution: 300dpi) {
    img {
        width: 200px;
    }
}

Combining Multiple Conditions

@media (min-width: 600px) and (max-width: 1200px) {
    body {
        background-color: yellow;
    }
}

Using Media Queries in HTML & JavaScript

1. In HTML (for Responsive Images)

<picture>
    <source media="(max-width: 600px)" srcset="small.jpg">
    <source media="(max-width: 1200px)" srcset="medium.jpg">
    <img src="large.jpg" alt="Responsive Image">
</picture>

2. In JavaScript (Using matchMedia)

if (window.matchMedia("(max-width: 600px)").matches) {
    console.log("Screen is less than 600px wide");
}

Best Practices

  • Mobile-First Approach: Start designing for smaller screens and add media queries for larger screens.
  • Use Relative Units: Use em, %, or rem instead of fixed px values.
  • Group Media Queries: Instead of scattering media queries, group them together for better readability.
  • Test on Real Devices: Use browser dev tools and actual devices for testing.

Conclusion

Media Queries are essential for creating responsive websites. By using them effectively, you can ensure that your website looks great on all devices.
